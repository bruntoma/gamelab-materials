Z čeho se skládá hra

Každá 2D hra, od Super Maria po Hollow Knight, stojí na stejných stavebních kamenech. V této lekci se naučíme, jak se jmenují a hlavně jak spolu souvisí.

Ukázky jsou v GameMakeru, ale u každé najdeš i přepínač na Godot, Unity a Scratch. Zkus si všechno naklikat: šedé rámečky s nadpisem jako v editoru jsou interaktivní.

AssetVšechno, co je v projektu: obrázky, zvuky, objekty, scény. SpriteObrázek nebo animace. Neví, kde je, jen jak vypadá. ObjektPředpis: jak věc vypadá a jak se chová. InstanceKonkrétní kus objektu, který žije ve scéně. ScénaMísto, kde se hra odehrává: úroveň, menu, Game Over. KameraUrčuje, kterou část scény právě vidíme.
Pojem 1 · Asset

Asset: dílek ve stavebnici

Asset (čti „eset“) je cokoli, z čeho se hra skládá a co najdeš v projektu: obrázky, zvuky, písma, objekty, scény i skripty. Samy o sobě nic nedělají. Hra vznikne teprve tím, jak je poskládáš dohromady.

Projekt je krabice s Legem. Assety jsou jednotlivé kostičky.

Assety se navzájem používají. Objekt mince potřebuje obrázek mince a zvuk cinknutí. Scéna potřebuje objekty, které v ní budou. Klikni na asset vlevo a podívej se, s čím je propojený.

Asset Browserprojekt: Herní dílnaKlikni na položku
Tip

Pojmenovávej assety s předponou podle typu: spr_ sprite, obj_ objekt, snd_ zvuk, rm_ scéna (room). V kódu pak hned poznáš, co je co, a nestane se, že se sprite a objekt jmenují stejně.

Assety najdeš v panelu Asset Browser. Nový asset vytvoříš pravým klikem → Create. Typy: Sprites, Sounds, Objects, Rooms, Scripts, Fonts, Tile Sets, Paths, Sequences a další. V kódu se na asset odkazuješ přímo jménem:

// zahraj zvuk (asset snd_mince), priorita 1, neopakovat
audio_play_sound(snd_mince, 1, false);

// přepni na jinou scénu (asset rm_level2)
room_goto(rm_level2);

Assety jsou obyčejné soubory v panelu FileSystem, cesta začíná res://. Obrázky .png, zvuky .wav/.ogg, scény .tscn, skripty .gd. Godot jim říká resources.

# načti zvuk ze souboru a přehraj ho
var zvuk = preload("res://zvuky/mince.wav")
$AudioStreamPlayer.stream = zvuk
$AudioStreamPlayer.play()

Assety jsou v okně Project ve složce Assets/. Do skriptu je obvykle nedostáváš jménem, ale přetáhneš je myší do políčka v Inspectoru.

public AudioClip zvukMince;   // políčko v Inspectoru, přetáhneš sem soubor

void SebralMinci() {
    AudioSource.PlayClipAtPoint(zvukMince, transform.position);
}

Scratch soubory neukazuje. Assety jsou rozdělené do záložek: Kostýmy (obrázky postavy), Zvuky a Pozadí (u scény). Postavy jsou v seznamu pod scénou.

když kliknu na zelenou vlajkupusť zvuk [Mince] a čekej
Pojem 2 · Sprite

Sprite: obrázek, který umí pózovat

Sprite je obrázek, kterým se ve hře něco kreslí. Může mít víc snímků (frames). Když se rychle střídají, vznikne animace, stejně jako v kreslené knížce, kterou listuješ palcem.

Sprite má pár důležitých vlastností:

  • Rozměr v pixelech a počet snímků s rychlostí animace (FPS, snímky za sekundu).
  • Origin (počátek): bod, za který sprite „drží“ na souřadnicích x, y. Kolem něj se sprite i otáčí a zrcadlí.
  • Kolizní maska: oblast, která se počítá při nárazech. Nemusí být stejná jako obrázek.
Sprite Editorspr_minceKlikni do mřížky a přesuň origin

Sprite (editor)

Instance ve hře

Křížek je poloha instance (x, y). Sprite se nakreslí tak, aby jeho origin ležel přesně na křížku. Zkus origin přesunout a pak sprite otáčet.

Nastavení

!

Sprite neví, kde je, ani co dělá. Je to jen obrázek. Polohu, pohyb a chování mu dává instance objektu, která ho používá. Jeden sprite může používat víc objektů, třeba stejná mince pro „minci“ i „zlatou minci“.

V Sprite Editoru nastavíš snímky, FPS, origin (rozbalovací nabídka nebo klik do obrázku) a Collision Mask. Instance pak sprite ovládá vestavěnými proměnnými:

sprite_index = spr_hrac_beh;  // který sprite instance kreslí
image_index  = 0;             // aktuální snímek (od nuly)
image_speed  = 1;             // 1 = rychlost podle FPS spritu, 0 = stop
image_angle  = 45;            // natočení ve stupních, proti směru hodinek
image_xscale = -1;            // zrcadlení: postava se dívá doleva

Obrázek je Texture. Kreslí ho uzel Sprite2D, animace dělá AnimatedSprite2D se sadou SpriteFrames. Origin nastavuješ vlastnostmi centered a offset. Kolize je zvláštní uzel CollisionShape2D.

$AnimatedSprite2D.play("beh")        # spusť animaci "beh"
$AnimatedSprite2D.speed_scale = 1.0   # rychlost animace
$AnimatedSprite2D.flip_h = true       # zrcadlení
rotation_degrees = 45                 # natočení celého uzlu

Obrázek importuješ s Texture Type: Sprite (2D and UI). Origin se jmenuje Pivot (nastavíš ho v Sprite Editoru). Na scéně ho kreslí komponenta SpriteRenderer, animuje Animator a kolize řeší Collider2D.

SpriteRenderer sr = GetComponent<SpriteRenderer>();
sr.sprite = spriteBeh;   // vyměň obrázek
sr.flipX = true;         // zrcadlení
transform.rotation = Quaternion.Euler(0, 0, 45);

Sprite je ve Scratchi kostým. Animace = přepínání kostýmů. Origin je střed kostýmu (v editoru kostýmu ho posuneš tak, že posuneš obrázek vůči středovému křížku).

když kliknu na zelenou vlajkuopakuj stáledalší kostýmčekej (0.125) sekund
Pojem 3 · Objekt a instance

Objekt je vykrajovátko, instance jsou perníčky

Objekt je předpis. Říká, jak má věc vypadat (který sprite použije) a jak se má chovat: co udělá, když vznikne, co dělá v každém snímku hry, co se stane, když do ní něco narazí. Těmto situacím se říká události (events).

Instance je jeden konkrétní kus vyrobený podle objektu a umístěný ve scéně. Objekt obj_slime máš v projektu jednou, ale slizounů ve scéně může být dvacet.

Všechny instance sdílí chování objektu, ale každá má vlastní proměnné: polohu x, y, počet životů hp. Proto může jeden slizoun zemřít a ostatní žijí dál.

Co se stalo (v GML)

?

Ve skutečném GameMakeru se změna objektu projeví až po novém spuštění hry. Tady ji vidíš hned, aby bylo jasné, co patří objektu a co instanci.

Objekt vytvoříš v Asset Browseru, přiřadíš mu sprite a přidáš události (Create, Step, Draw, Collision…). Instance přetáhneš myší do scény v Room Editoru, nebo je vytvoříš kódem:

// Create event objektu obj_slime: běží jednou, když instance vznikne
hp = 3;

// kdekoli jinde: vytvoř novou instanci na vrstvě "Instances"
var s = instance_create_layer(200, 300, "Instances", obj_slime);
s.hp = 10;   // změní hp jen téhle jedné instanci

// počet instancí objektu ve scéně
show_debug_message(instance_number(obj_slime));

Godot nemá „objekty“. Předpisem je scéna (.tscn) se skriptem, např. slime.tscn. Instanci vytvoříš přetažením scény do jiné scény, nebo kódem. Pozor: slovo „scéna“ v Godotu znamená předpis i úroveň.

const SlimeScena = preload("res://slime.tscn")

func _ready():
    var s = SlimeScena.instantiate()   # vyrob instanci
    s.position = Vector2(200, 300)
    s.hp = 10                          # jen téhle instanci
    add_child(s)                       # vlož ji do hry

Předpisem je Prefab: GameObject s komponentami, uložený jako asset. Každý GameObject ve scéně je pak instance. Chování píšeš jako komponentu (skript), např. Slime.cs.

public GameObject slimePrefab;   // přetáhni prefab v Inspectoru

void Start() {
    GameObject s = Instantiate(slimePrefab, new Vector3(2, 3, 0), Quaternion.identity);
    s.GetComponent<Slime>().hp = 10;   // jen téhle instanci
}

Objekt je postava. Instance jsou klony: kopie postavy, které běží podle stejných skriptů. Každý klon má vlastní polohu a proměnné „jen pro tuto postavu“.

když kliknu na zelenou vlajkuopakuj (5) krátvytvoř klon [sebe]když startuji jako klonskoč na [náhodná pozice]nastav [hp] na (3)
Pojem 4 · Scéna (room)

Scéna: jeviště, na kterém se hraje

Scéna (v GameMakeru room, místnost) je místo, kde se hra odehrává. Scénou může být úroveň, hlavní menu i obrazovka „Game Over“. Má svou šířku a výšku v pixelech a rozmisťuješ do ní instance objektů.

Scéna se skládá z vrstev. Jsou jako průhledné fólie položené na sobě: dole pozadí, nad ním dlaždice terénu, navrchu instance. Co je ve vyšší vrstvě, překryje to, co je pod ním.

Scéna je divadelní jeviště. Kulisy jsou vzadu, herci vpředu.

V Room Editoru nastavíš velikost scény a vrstvy (Background, Tiles, Instances, Assets). Každá vrstva má depth: čím menší číslo, tím víc vepředu. První scéna v seznamu Room Order se spustí jako první.

room_goto(rm_level2);        // přejdi do jiné scény
room_restart();              // začni tuhle scénu znovu
var w = room_width;          // šířka aktuální scény v pixelech
layer_set_visible("Tiles", false);  // skryj vrstvu

Úroveň je také scéna: strom uzlů, ve kterém jsou instance jiných scén (hráč, mince…). Vrstvy řešíš pořadím uzlů ve stromu a vlastností z_index, pozadí třeba uzlem ParallaxBackground, terén TileMapLayer.

get_tree().change_scene_to_file("res://level2.tscn")
get_tree().reload_current_scene()
$TileMapLayer.visible = false

Úroveň je Scene (soubor .unity). Scény, které se mají dostat do hry, přidáš v Build Profiles. Pořadí kreslení 2D řeší Sorting Layers a Order in Layer na SpriteRendereru.

using UnityEngine.SceneManagement;

SceneManager.LoadScene("Level2");
SceneManager.LoadScene(SceneManager.GetActiveScene().name); // restart

Scratch má jen jednu scénu (Stage) o velikosti 480 × 360 bodů. Další „úrovně“ se dělají přepnutím pozadí. Vrstvy řešíš bloky „přesuň se do popředí / dozadu“.

když přijmu zprávu [level 2]změň pozadí na [Les]přesuň se do vrstvy [popředí]
Pojem 5 · Kamera a viewport

Kamera: kameraman ve tvé scéně

Scéna bývá mnohem větší než obrazovka. Kamera určuje, kterou část scény právě vidíme. Je to obdélník ve scéně, který má polohu (x, y) a velikost (šířku a výšku).

Viewport je místo na obrazovce, kam se záběr kamery vykreslí. Kamera říká co se snímá, viewport kam a jak velké se to ukáže.

Když kameru zmenšíš a viewport zůstane stejný, obraz se přiblíží. Když se hráč pohne a kamera ho sleduje, vypadá to, že ujíždí celý svět. Ve skutečnosti se hýbe jen kamera.

Nápis „MINCE 0/12“ se s kamerou nehýbe. Kreslí se totiž na obrazovku, ne do scény. V GameMakeru se na to používá událost Draw GUI, v Godotu uzel CanvasLayer, v Unity Canvas.

x, y

Najeď myší na obraz. Souřadnice na obrazovce a ve scéně se liší o polohu kamery a zvětšení. GameMaker v mouse_x a mouse_y vrací už přepočítané souřadnice ve scéně.

V Room Editoru → Viewports and Cameras zaškrtni Enable Viewports a u Viewport 0 Visible. Camera Properties = velikost kamery, Viewport Properties = velikost na obrazovce, Object Following = koho sledovat. Nebo to napiš sám (Step event hráče):

var cam = view_camera[0];
var w = camera_get_view_width(cam);
var h = camera_get_view_height(cam);

// vycentruj kameru na hráče, ale nepouštěj ji ven ze scény
var cx = clamp(x - w / 2, 0, room_width  - w);
var cy = clamp(y - h / 2, 0, room_height - h);
camera_set_view_pos(cam, cx, cy);

Přidej uzel Camera2D jako potomka hráče: bude ho sledovat sám. Hranice nastavíš vlastnostmi limit_*, přiblížení zoom. Velikost viewportu je velikost okna (Project Settings → Display → Window).

$Camera2D.limit_left = 0
$Camera2D.limit_top = 0
$Camera2D.limit_right = 1920
$Camera2D.limit_bottom = 480
$Camera2D.zoom = Vector2(2, 2)               # 2× přiblížení
$Camera2D.position_smoothing_enabled = true  # plynulé sledování

Ve scéně je Main Camera. Pro 2D ji přepni na Orthographic. orthographicSize je polovina výšky záběru ve světových jednotkách. Na pokročilé sledování je balíček Cinemachine.

public Transform hrac;

void LateUpdate() {
    // kamera stojí na pozici hráče, z = -10 aby byla "před" scénou
    transform.position = new Vector3(hrac.position.x, hrac.position.y, -10f);
}
// Camera.main.orthographicSize = 5f;   // menší číslo = větší přiblížení

Scratch kameru nemá, scéna je vždy 480 × 360. Kamera se dá předstírat: pamatuješ si proměnnou kameraX a každou postavu kreslíš posunutou o ni. Přesně tohle za tebe dělají ostatní enginy.

Jak to do sebe zapadá

Projekt obsahuje assety. Objekt používá sprite (a třeba zvuk). Ve scéně žijí instance objektů. Kamera snímá výřez scény a viewport ho ukáže na obrazovce. Najeď na pojem nebo na něj klikni a uvidíš jeho vazby.

Úkol: první scéna s kamerou

  1. Vytvoř sprite spr_hrac (stačí čtverec 32 × 32) a nastav mu origin na Middle Centre.
  2. Vytvoř objekt obj_hrac, přiřaď mu sprite a do události Step napiš pohyb šipkami: x += (keyboard_check(vk_right) - keyboard_check(vk_left)) * 4;
  3. Vytvoř sprite a objekt obj_mince. Do scény polož 1 hráče a aspoň 5 mincí. Kolik máš objektů a kolik instancí?
  4. Zvětši scénu na 2000 × 768 px. V Viewports and Cameras zapni viewport 0, kameru 640 × 360, viewport 1280 × 720 a Object Following nastav na obj_hrac.
  5. Bonus: zmenši kameru na 320 × 180. Co se stalo s obrazem a proč?
